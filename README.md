# ProjectArchive

Lore site for fictional pieces of work.

## Development

Install dependencies with `npm install`, then start the development server with `npm run dev`.

## React + Vite

This project uses React and Vite. Vite provides hot module replacement and ESLint integration.

The React plugin supports Fast Refresh:

- [@vitejs/plugin-react](https://github.com/vitejs/vite/tree/main/packages/plugin-react)
- [@vitejs/plugin-react-swc](https://github.com/vitejs/vite/tree/main/packages/plugin-react-swc)

The React Compiler is enabled. See the [React documentation](https://react.dev/learn/react-compiler) for more information.
